# FLYING FURY

## Game Description

**Flying Fury** is a 2D action-strategy game developed using **C/C++ and iGraphics**. The main objective is to launch different birds using a slingshot and destroy blocks and enemies. The game contains **5 levels**, with increasing difficulty and different challenges.

## Features

* 5 playable levels
* Multiple birds with different abilities
* Slingshot and aiming system
* Trajectory indicator
* Destructible blocks
* Enemy and collision system
* Special bird abilities
* Level progression
* Score tracking system
* Help and Score menu

## Main Menu

* **START** — Starts the game from Level 1
* **SCORE** — Shows Highest, Last, and Total Score
* **HELP** — Shows game instructions and controls
* **EXIT** — Closes the game

## Gameplay

The player selects a bird and uses the slingshot to aim and launch it toward the target. The trajectory indicator helps with aiming. Players must destroy blocks and enemies using limited birds and their special abilities.

After completing a level, the player progresses to the next level. The game continues through **Level 5**, which is the final challenge.

## Controls

| Action      | Control         |
| ----------- | --------------- |
| Select Bird | `1 / 2 / 3 / 4` |
| Aim         | Mouse           |
| Launch      | Mouse           |
| Pause/Menu  | `ESC`           |

## Scoring System

The game maintains three types of scores:

* **Highest Score** — Highest score achieved
* **Last Score** — Score from the most recent game
* **Total Score** — Accumulated score from completed games
